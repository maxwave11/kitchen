# Кухня-гостиная: 3D-планировка

Репозиторий для планировки кухни-гостиной.

Запуск на Windows — двойной щелчок по [start-planner.bat](start-planner.bat). Планировщик откроется в браузере по адресу [127.0.0.1:8765](http://127.0.0.1:8765/kitchen-living.html). Для работы нужен Python 3.11 с PyYAML. Окно запуска оставьте открытым, пока работаете с планировщиком.

- `rooms/` — комнаты в формате planhaus (появится после замеров)
- `viewer/` — готовые 3D-модели (HTML, открываются в браузере)
- [AGENTS.md](AGENTS.md) — инструкции проекта и список руководств из `.agents/skills/`.
- `tools/planhaus/` — движок проверки зазоров и шаблоны (planhaus, MIT)
- `tools/room3d/` — генератор 3D-модели на three.js

Демо: `viewer/sample-living-room.html` — пример комнаты из planhaus, чтобы посмотреть, как выглядит 3D.
