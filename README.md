# Кухня-гостиная: 3D-планировка

Репозиторий для планировки кухни-гостиной вместе с Claude.

- `rooms/` — комнаты в формате planhaus (появится после замеров)
- `viewer/` — готовые 3D-модели (HTML, открываются в браузере)
- `.claude/skills/` — скиллы, которые Claude использует в этом проекте (список в `CLAUDE.md`)
- `tools/planhaus/` — движок проверки зазоров и шаблоны (planhaus, MIT)
- `tools/room3d/` — генератор 3D-модели на three.js

Демо: `viewer/sample-living-room.html` — пример комнаты из planhaus, чтобы посмотреть, как выглядит 3D.
