Управление мышью Вращение: левая кнопка / один палец. Сдвиг: правая кнопка / два пальца. Масштаб: колесо / щипок. Клик по объекту выбирает его, клик по пустому месту или Esc снимает выбор.
Перемещение: второй клик по уже выбранному предмету включает стрелки — красная вдоль стены, зелёная вверх, синяя от стены / к стене; квадраты между стрелками двигают сразу по двум осям. Шаг 0,5 см, границы те же, что у ползунков, Ctrl+Z отменяет.
Полёт: W/S — вперёд/назад, A/D — влево/вправо, Q/E — вниз/вверх. Скорость: − / + (=).

Помещения

Выберите стену, проём или предмет в списке или кликните по нему на сцене.
