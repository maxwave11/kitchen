Отменить Вернуть
Вращение вокруг центра: левая кнопка / один палец. Сдвиг: средняя кнопка / два пальца. Масштаб: колесо / щипок. Осмотреться (повернуть голову, камера стоит на месте): правая кнопка. Клик по объекту выбирает его, клик по пустому месту или Esc снимает выбор.
Перемещение: клик по предмету выбирает его и показывает стрелки — красная вдоль стены, зелёная вверх, синяя от стены / к стене; квадраты между стрелками двигают сразу по двум осям. Шаг 0,5 см, Ctrl+Z отменяет. Предмет можно ставить куда угодно.
Каждый следующий клик по нему же: кольцо поворота в горизонтальной плоскости (шаг 45°), затем контролы пропадают (предмет остаётся выбранным), потом снова стрелки. Выбор из списка справа показывает только рамку.
Полёт: W/S — вперёд/назад, A/D — влево/вправо, Q/E — вниз/вверх. Скорость: − / + (=).
