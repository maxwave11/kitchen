# Этап 0: прототип трассировки путей (2026-11-08)

> С этапа 2 режим встроен во вьюер (`tools/room3d/render_mode.js`, кнопка «Рендер»); эта папка — история прототипа и его выводы.
> Тестовую страницу можно пересобрать скриптом ниже, если понадобится сравнить.

Отдельная тестовая страница, вьюер не тронут. Удалить прототип = удалить эту папку и `viewer/pathtrace-test.{html,js}`.

```
py -3.11 tools/room3d/build_room_3d.py rooms/kitchen-living.yaml -o viewer/kitchen-living.html
```

Открыть `http://localhost:<порт serve.py>/pathtrace-test.html`, кнопка «Рендер» внизу. Страница — копия собранного вьюера
с three.js r187 вместо r169, «ручкой» `window.__pt` к сцене и модулем `pathtrace-test.js`
(three-gpu-pathtracer 0.0.28 `WebGPUPathTracer` + денойзер OIDN `oidn-webgpu` 0.6.0, веса `rt_hdr_alb_nrm.tza` с jsDelivr).
Браузерная панель должна быть видна (скрытая останавливает requestAnimationFrame).

## Результат (RTX 4080, Chrome 152 в Claude, WebGPU)

- Работает: та же сцена three.js, без копии; BVH сцены строится за 50–225 мс.
- Скорость при 1024 × 768, 8 отражений: ~25–45 сэмплов/с; 256 сэмплов ≈ 7–10 с; OIDN ≈ 0,1 с.
  Для 1920 × 1080 ожидаем примерно в 2,6 раза дольше (оценка, не замер).
- Качество: настоящее переотражение, мягкие тени, тени реек от солнца, в ночном окне отражается комната,
  ленты и прожекторы светят физично. Плоские материалы (одноцветные стены, мебель) стали заметнее — это этап 4.

## Что пришлось учесть (перенести в этапы 1–3)

1. **r169 → r187 — сделано на этапе 1 (2026-11-08):** вьюер на r187; `reflect.call(mirror, …)` (Reflector в r187 читает `this`),
   `PCFShadowMap` вместо устаревшего `PCFSoftShadowMap`. Проверены AO, зеркало ТВ, тени, лампы и ленты (патч теней лент
   совместим), вид сверху и орто, выделение и гизмо, вся квартира; средняя яркость кадра та же (139,3 против 139,9 на r169).
2. **Невидимые боксы для клика** (`MeshBasicMaterial({ visible: false })`, один заполняет проём окна) трассировщик
   считает глухими — исключать меши с невидимым материалом.
3. **Стекло окна:** прозрачное стекло (`transmission`) без `visibleToShadowRays = false` даёт чёрный кадр с «искрами»:
   свет солнца и неба доходит только случайными путями. С флагом потери стекла учитываются в силе солнца и яркости неба (×0,7).
4. **Срезанные стены** должны быть видимыми на время рендера, иначе солнце светит в комнату сквозь них.
5. **Фальшивый свет вьюера** (полусфера, свет неба в стекле, отражение от пятна) выключать; небо — текстура окружения
   снаружи (у `DataTexture` строка 0 — низ, а не верх).
6. **Экспозиция:** оценка вьюера для честного рендера ярче нужного (подходит ×0,4) — нужна авто-экспозиция по картинке.
7. Вьюер в `applyMode` ставит цвет фона: выходить из рендера (вернуть сцену) раньше, чем вьюер применит новый режим.
8. Экраны ТВ и духовки (`Reflector`, свой шейдер) — заменены глянцевым чёрным материалом.
